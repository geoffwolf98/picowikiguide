# F5 then C: pictures always colour (a bigger picture buffer, made at
# start, so it restarts; the default from 0.9.5) or grey when short of
# room (0.9.3)
key down enter
type elizabeth ii
key enter
expect article "Elizabeth II" page=1/144
key f5
expect help pictures=colour
key c
expect help pictures=grey
key esc
expect article "Elizabeth II" page=1/144
expect colour=1
mem
restart
key f5
expect help pictures=grey
key c
expect help pictures=colour
key esc
expect article "Elizabeth II" page=1/144
mem
